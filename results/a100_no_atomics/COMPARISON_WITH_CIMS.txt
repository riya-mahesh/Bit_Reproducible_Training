A100 VS CIMS NON-ATOMICS EXPERIMENTS

Reproducibility: A100 plus seven CIMS configurations have matching hashes and logged loss bits for equivalent settings. 131 repro records in nine seed/batch/S groups; 64 RepDL records in five seed groups. All archived source manifests match.
This compares 43 A100 full runs with 280 CIMS full runs. All use two epochs, learning rate 0.01, S=3. The baseline uses batch 100 and seed 0.

ACCURACY / MEMORY
Repro five-seed mean test accuracy: 98.002%, sample SD 0.280 percentage points, identical for all configurations. RepDL: 97.960%, SD 0.135 percentage points, identical for all configurations. These are separate algorithm outputs; repro is not claimed to match RepDL bits.
Stock five-seed mean: A100 97.670%; CIMS range 97.820% to 98.068%. No statistical superiority claim follows from five seeds.
At baseline batch 100, repro peak PyTorch-allocated memory is 222.110 MiB on every configuration. This is the harness allocator metric, including data/evaluation, not total process VRAM.

INTERPRETATION
At batch 100 A100 has the lowest repro step time: 1.18–1.23x lower-time ratio versus cuda2, 1.09–1.11x versus cuda3, and 3.94–3.96x versus cuda5.
The ranking is workload-dependent. At batch 1000 cuda5/CUDA 12.4 records 10.025 ms versus A100 11.445 ms. Do not extrapolate the batch-100 ranking to all batches.
The RTX 4070 shows higher times for stock as well as repro at batch 100. The gap is therefore not evidence by itself of a defect specific to reproducible arithmetic. CPU/launch/synchronization overhead and runtime conditions need separate measurement.
cuda5 RepDL/CUDA 12.6 baseline run medians vary from 15.072 to 25.851 ms; its aggregate should not be interpreted as a clean CUDA-version regression.

LIMITS
Pre-existing GPU processes were recorded for A100 (PID 7206, 420 MiB), cuda2/CUDA 12.6 and cuda3/CUDA 12.4. Their presence does not prove active overlap throughout the run. Repeat performance measurements with an idle/reserved GPU before definitive speedup claims.
Empty startup process lists do not establish uninterrupted exclusive GPU use.
A100 uses PyTorch 2.6.0+cu124 but nvcc 12.6.77. CIMS uses matching wheel/toolkit versions (12.4/2.6.0; 12.6/2.7.1; 13.0/2.9.0). CPUs, drivers and Python versions also differ. These are whole-system comparisons.
A100 has four Nsight captures and three extra repro profile repeats. Each CIMS configuration has two weight-gradient captures and one repro profile run. Profiler timing is not included in the baseline timing table.
